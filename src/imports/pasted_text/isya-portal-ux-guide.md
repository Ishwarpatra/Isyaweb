Master Figma UI/UX Implementation Guide: ISYA PortalDesign System Upgrade: Ultra-Trending Space-Age Aesthetic & Mission Control ArchitectureTarget Tool: FigmaVersion: 3.0 (Comprehensive Master Document - Expanded Architecture & Functional UX)This master brief instructs the UI/UX design team on how to translate modern, high-end CSS trends (Bento Grids, Glassmorphism, Scrollytelling, Tactile Brutalism) and production-grade system architecture into a scalable, accessible Figma file for the International Space Youth Association (ISYA) Web Portal.The psychological goal of this aesthetic is to treat the youth demographic (ages 14-24) not as passive "students on a website," but as active "cadets in a command center." This requires a shift from standard web paradigms to highly tactile, immersive, app-like experiences.PHASE 1: System Architecture & Foundations1. Atomic Design & Component StructureConcept: Scalable, modular design system built for long-term maintenance and rapid iteration.Figma Instructions:Atoms to Organisms Methodology: Do not design full pages or screens first. You must start by designing Atoms (the smallest indivisible units like buttons, text inputs, labels, and SVG icons) as Main Components on a dedicated "Sticker Sheet" page. Combine these Atoms into Molecules (e.g., a search bar input paired with a submit button and a dropdown), and then aggregate those into Organisms (global navigation bars, complex Bento Grid cards, and footer assemblies).Component Properties: Utilize Figma's Component Properties heavily. Instead of creating 20 variants of a button, create one master button with Boolean properties (e.g., Show Icon Left, Show Icon Right), Text properties (e.g., Label Text), and Variant properties (e.g., State: Hover, Type: Primary).Nested Instances & Cascading Updates: Build complex screens exclusively using nested component instances. If the engineering team requests an adjustment to the primary button's outer glow, it should only be changed on the master "Atom" component, instantly and flawlessly cascading that change across the entire 50+ screen portal prototype.2. The 8-Point Spatial GridConcept: Mathematical layout precision for perfect scaling across high-density displays (Retina, 4K).Figma Instructions:The "Why": Screen sizes and pixel densities vary wildly. Designing on an 8-point grid ensures that all elements scale cleanly without half-pixel blurring, as 8 is evenly divisible by most standard screen scaling multipliers (@1.5x, @2x, @3x).Desktop Layout Grids: On all desktop frames (1440px wide), apply a Layout Grid: Columns, Count: 12, Type: Stretch, Margin: 64px, Gutter: 24px.Tablet/Mobile Breakpoints: Create strict breakpoints for Tablet (768px wide, 8 columns, 32px margin) and Mobile (375px wide, 4 columns, 16px margin).Nudge Amount & Spacing: In Figma preferences, set your "Big Nudge" amount (Shift + Arrow Key) to 8px. All spacing, heights, paddings, and margins must be multiples of 8 (e.g., 8, 16, 24, 32, 40, 48, 64). Exception: 4px can be used for extreme micro-spacing within tight Atoms.3. Design Tokens (Figma Variables Setup)Concept: Native CSS Variables for centralized control, ensuring a 1:1 match with the developer's Tailwind/CSS codebase.Figma Instructions:Open the Local Variables panel and define the following before designing any structural screens. Never use manual hex codes or pixel inputs for properties covered by variables.Colors (Dark Mode/Space Aesthetic Only):bg/deep-space: #0B0F19 (The absolute void. Base background.)surface/glass: rgba(17, 24, 39, 0.4) (Used for elevated cards and panels.)accent/nebula-pink: #EC4899 (Primary action color. Use sparingly for maximum impact.)accent/stellar-blue: #3B82F6 (Secondary action, data visualization, and links.)semantic/success-green: #10B981 (System nominal, successful uploads, online status.)semantic/critical-orange: #F97316 (System warnings, destructive actions, offline status.)text/primary: #FFFFFF (Headings and active inputs.)text/secondary: #9CA3AF (Paragraphs, subtext, and placeholders.)Numbers (Spacing, Radii & Elevations):spacing/xs: 4px | spacing/sm: 8px | spacing/md: 16px | spacing/lg: 24px | spacing/xl: 48px | spacing/xxl: 96pxradius/sharp: 4px | radius/inner: 8px | radius/outer: 16px | radius/pill: 999pxelevation/glow: Blur 24, Y 0, Spread 4 (Used with accent colors for active states).PHASE 2: Visual Aesthetic (The "Mission Control" Look)4. Glassmorphism & Cosmic TexturesConcept: Combining deep space immersion with advanced aerospace interface materials (backdrop-filter: blur()).Figma Instructions:Cockpit Glass Layering: For content cards and modals, you must build the Glassmorphism effect in layers to avoid legibility issues. Create a Frame. Apply the surface/glass variable. Under Effects, add Background Blur set strictly to 16 or 24.Tactile Edge Highlights: To separate the glass from the background void, add an inside Stroke of 1px. Set the stroke to a Linear Gradient (Top: White 20% opacity fading to Bottom: White 0% opacity). This mimics ambient command-center light catching the upper edge of the glass panel.Stardust Noise & Material Grain: Pure flat colors look too digital. Create a top-level overlay Frame covering the entire UI design. Fill it with a high-resolution static noise/grain image tile. Set the blend mode to Screen or Soft Light and reduce opacity to 2% - 5%. Lock the layer. This gives the deep navy background physical material presence.5. Tactile Brutalism & HUD ElementsConcept: Breaking away from "friendly software" into "aerospace hardware" using clip-path() and custom vector aesthetics.Figma Instructions:Chamfered Corners (The Hardware Look): For large hero banners or critical warning modals, reject standard border-radius. Instead, use the Pen Tool (P) to draw vector shapes with 45-degree angled corners (mimicking cut spacecraft plating).Mission Control Crosshairs: Create a reusable Component consisting of a delicate 1px + symbol or [ ] brackets. Absolute position these -4px outside the corners of your main containers. This creates a "HUD targeting" or schematic aesthetic common in jet fighter interfaces or NASA readouts.Glowing Brutalist Shadows: Reject soft, dark drop shadows (which disappear on dark backgrounds anyway). Under Effects, add a Drop Shadow, set X and Y to 0, Blur to 24, and use the accent/nebula-pink or accent/stellar-blue variable at 60% opacity to make elements look like they are emitting light rather than casting a shadow.6. Kinetic & Telemetry TypographyConcept: Typography as data. Using Variable Fonts and monospaced readouts to establish technical authority.Figma Instructions:Variable Primary Font Stack: Use a modern, highly legible sans-serif (e.g., Inter Variable, Geist, or Roobert). Use Figma's Variable Font Axes slider to perfectly tune the weight. Ensure paragraphs have a generous line-height (150% to 160%) to reduce eye strain against the dark background.Telemetry Monospace: This is critical. For ALL dates, tags, metadata, user IDs, and small labels, strictly use a technical monospace font (e.g., JetBrains Mono, Space Mono). Style these as data readouts using all-caps, reduced tracking (letter-spacing), and slashes/prefixes (e.g., // SYSTEM_STATUS: ONLINE or [DATELOG: 2026.05.21]).7. Brand Identity & Responsive Logo IntegrationConcept: Seamlessly embedding the ISYA brand into the "Mission Control" aesthetic without breaking the UI flow.Figma Instructions:Logo Extraction & Transparency: The provided ISYA logo (Rocket with orbital rings) must be vectorized (recreated as an SVG) or cleanly masked to remove the solid dark background. The logo elements must float seamlessly on the bg/deep-space or surface/glass backgrounds without a visible, clashing bounding box.Component Variants: Create a Main Component for the Logo with three distinct responsive variants based on available real estate:Full Lockup: Rocket mark + "ISYA" text + "International Space Youth Association" subtext. (Use this for the Landing Page hero, loading screens, or the massive footer).Compact: Rocket mark + "ISYA" text. (Use this for the primary top Navigation Bar).Mark Only: Just the Rocket mark. (Use this for mobile headers, tight spaces, avatar fallbacks, and favicons).Navbar Integration & Hover: In the Navigation Bar, size the Compact logo to a max-height of 40px (exactly 5 units of the 8pt grid). Apply a While Hovering -> Smart Animate interaction that scales the logo up to 105% and adds a subtle accent/nebula-pink drop shadow (blur 12, 40% opacity) to signify it as an interactive "Return Home" link.Typography Harmony: Ensure the "ISYA" text within the logo lockup visually compliments the Inter or JetBrains Mono font stack. Avoid conflicting serif fonts.PHASE 3: Modern Layout Trends8. Bento Grids (Modular Data Organization)Concept: display: grid;, Container Queries. Organizing complex data into digestible, distinct, and asymmetrical visual blocks.Figma Instructions:Auto Layout Wrap: For Dashboard overviews, the Blog landing page, and the Media Hub, use Figma's Auto Layout. Select the Wrap arrow to mimic CSS Flex/Grid wrapping behavior perfectly.Asymmetrical Hierarchy: Do not make every card the same size; this looks like a generic template. Create specific variants of your Bento cards based on content importance:1x1 (Standard Square): Used for quick stats, small blog posts, or author bios.2x1 (Wide Span): Used for featured podcasts, panoramic imagery, or timeline graphs.1x2 (Tall Span): Used for vertical media, upcoming event lists, or live-feed chat blocks.Set these nested cards to "Fill Container" or specific minimum widths in Auto Layout to ensure they snap responsively to the grid as the frame resizes.9. Cinematic Scrollytelling (Prototyping)Concept: animation-timeline: scroll(). Websites that behave like interactive films, revealing data as the user progresses.Figma Instructions:Staggered Entrances: Break the landing page into distinct, desktop-sized vertical Frames (e.g., Hero, Pillars, Global Impact).Prototyping the Scroll: Use invisible trigger boxes at the bottom of frames. On Mouse Enter of the trigger zone, transition to the next Frame using Smart Animate -> Slow -> 800ms.The Parallax Setup: Elements in the new Frame should be placed at their final, resting positions (100% opacity and Y: 0). In the previous Frame, those same elements should exist but be styled at 0% opacity and Y: 40px (pushed down slightly). When Smart Animate triggers, the elements will smoothly glide up and fade in, perfectly simulating an expensive, code-heavy scroll reveal for client presentations.PHASE 4: UX, States & Accessibility10. Component State Machines & Micro-AnimationsConcept: Explicit interactive feedback loops so the user always knows the system is responding.Figma Instructions:Interactive States: Every interactive element (buttons, links, form inputs) must be a Component Set with the following mandatory Variants: Idle, Hover, Focus (Keyboard), Active (Pressed), Disabled, and Loading.Prototyping the Glow (Hover): Link Idle to Hover with While Hovering -> Smart Animate (300ms, Ease Out). In the Hover variant, slightly increase the opacity of the glassmorphism, scale inner icons to 105%, and increase the colored glow drop-shadow.Tactile Click (Active): Link Hover to Active using While Pressing. Scale the entire button down to 96% to simulate the physical resistance and press of a hardware button.The Loading State: Never use a generic gray spinner. Replace the button text with a custom SVG orbital loader (e.g., a tiny rocket circling a planet) to maintain thematic immersion even while waiting for database queries.11. Gamification & Impact TelemetryConcept: Driving social impact and user retention through visually rewarding UX.Figma Instructions:Avatar Progression System: Design an Avatar component set with variants for user levels (e.g., Level 1: "Cadet", Level 2: "Specialist", Level 3: "Commander"). Upgrade the visual borders of the avatar based on their tier—starting as a simple gray dashed line, evolving into a solid blue ring, and finally a glowing pink geometric hexagon for top contributors.Impact Dashboard (Mission Control): Design live data visualization components (using Recharts/D3 plugin placeholders) showing real-time community metrics. Instead of boring bar charts, design "Orbital Scatter Plots" or "Radar Sweeps" showing "Lines of Open Source Code Contributed" or "Active Global Projects."12. Advanced Accessibility (a11y) & Error RecoveryConcept: Universal usability over aesthetics. The coolest design fails if it cannot be used by everyone.Figma Instructions:Keyboard Focus First: For the Focus variant of all buttons, inputs, and links, add a highly visible, offset outline (Stroke: 2px, Offset: 4px) using the accent/nebula-pink color. This ensures users navigating via the Tab key can clearly see their current location against the dark background.Progressive Disclosure (Registration): For the Registration and Onboarding flow, do not design one massive, intimidating form. Design a multi-step stepper component (e.g., Step 1: Identification -> Step 2: Clearances -> Step 3: Launch) to drastically reduce cognitive overload and form-abandonment rates.Thematic Error States: For the Error variant of inputs (e.g., a wrong password), use the semantic/critical-orange variable to turn the input border and text red. However, do not just rely on color (which fails for colorblind users). You must include a monospace Telemetry error message directly below the input (e.g., // ERR_CODE: 401 - INSUFFICIENT_SECURITY_CLEARANCE. RETRY.) to provide clear, actionable, and thematic feedback.Contrast Checking: Run the Stark plugin or Figma's native contrast checker on all text/secondary layers. Ensure the gray text on the deep navy background meets at least WCAG 2.1 AA standards (a contrast ratio of 4.5:1 or higher). If it fails, lighten the gray.
